## AS4837 是什么，Akile 为什么分成 ISP 和普通两档

AS4837 是中国联通的骨干线路，圈内常说的 CUVIP、CUII 都属于这个体系。Akile 用它做洛杉矶回国的优化路径，官方对 LAX4837-ISP 的描述是"三网回程 CUVIP(4837)"，即电信、联通、移动三家回程都走这条线。

关于它到底优化的是哪家运营商，社区一直有分歧。2023 年 hostloc 有个讨论帖，楼主说"Technovm、akile 好像都是电信专用"，楼下直接反驳："4837 怎么可能是电信专用，就算专用也是联通，电信还是老老实实用 CN2。"楼主的回应是"看评测就电信能用，akile 自己也说了是电信优化"。这段对话是 2023 年 11 月的，只能当历史参考；同一个帖子里有用户说自己同时买了 Technovm、akile、WePC 三家实测，本地电信下载都在 100M 以上，akile 到国内接近 200M，国际带宽表现最强。那也是 2023 年的数据，不能当作今天的速度承诺。

真正决定这两档差价的，是 IP。ISP 版给的是双 ISP 住宅属性 IP，普通版是优化过的机房 IP，两者跑的是同一条 AS4837 回程。对 Google、Claude 这类会看 IP 归属的平台来说，住宅属性的地址在风控模型里起点更高；对纯代理用途来说，这个差别换不来速度。

顺带说一个判断标准：账号能不能活，主要看 IP 信誉，也就是 Scamalytics 这类评分、地址有没有进代理和滥用数据库，而不是"住宅"两个字本身。干净的机房 IP 照样能用，被打脏的住宅 IP 也救不回来。Akile 的控制面板会实时显示 IP 信誉和流媒体解锁状态，买完不用自己逐项测。

**IP 被平台标记了能换吗？**
